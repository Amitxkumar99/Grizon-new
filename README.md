# AURA — Creative Agency & Digital Reality Studio

High-fidelity implementation of the **[AURA Creative Agency Template](https://21st.dev/@larsen66/templates/aura-svelte-gsap)** (by Yusuf Cengiz on 21st.dev).

Built with expressive motion, dark luxury aesthetics, serif typography, Lenis smooth scrolling, and GSAP animations.

## 🚀 Quick Start

```bash
# Start local server
npm start
```

Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## ✨ Implemented Sections & Features

1. **Floating Pill Navigation**: Dynamic expanding header, AURA SVG logo, anchor links, "Let's Talk" CTA, and full-screen mobile menu drawer.
2. **Magnetic Custom Cursor**: Custom cursor follower with hover expansion on interactive elements.
3. **Cinematic Hero**:
   - Animated `ascii-art.gif` background with radial vignette.
   - Dramatic headline: *"We craft digital experiences."* using `Instrument Serif`.
   - Mouse parallax effect on desktop.
4. **Interactive Manifesto**: ScrollTrigger-scrubbed word-by-word reveal from 10% opacity to pure white.
5. **Infinite Brands Marquee**: Smooth continuous brand logo ticker (Lumina, Ozone, Nexal, Aura, Vercel, Stripe, Linear, Figma) with soft edge gradients.
6. **Core Disciplines Showcase**: 3 large interactive cards (01 Digital Strategy, 02 Space & Web3, 03 Motion Identity) with hover radial glow and animated descriptions.
7. **Selected Works Table**: Minimalist interactive project list (Nike Forward, Ozone WebGL, Lumina App, Aura Engine) with sliding blue accent hover states.
8. **Client Testimonials Carousel**: Rotating client feedback quotes (Lumina, Nexal, Ozone) with animated transitions and clickable pagination dots.
9. **Animated Stats Counter**: ScrollTrigger count-up metrics ($200M+ Value, 45+ Awards, <60 Days Sprints, 120+ Partners).
10. **Interactive FAQ Accordion**: Expandable Q&A with animated Plus/Minus icons.
11. **Massive CTA & Footer**: "Have a project in mind?" with magnetic circular "Let's Talk" button, newsletter form, and social links.
