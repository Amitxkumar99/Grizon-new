## Data Flow

1. **User requests resource:** Browser sends `GET /` or `GET /about.html` to server on port 3000.
2. **Path & Route Resolution:** `server.js` decodes URL, maps root `/` to `/index.html`, and checks `fs.stat`.
3. **MIME & Header Assignment:** Server identifies file extension (`.html`, `.css`, `.js`, etc.), sets `Content-Type` with UTF-8 charset, and applies `Cache-Control: no-cache`.
4. **Streaming Response:** Server pipes read stream (`fs.createReadStream`) directly to response stream without buffering whole file in memory.
5. **Client Execution:** Browser parses HTML, loads Google Fonts (`Inter`, `JetBrains Mono`), fetches `css/styles.css`, and runs `js/main.js` on `DOMContentLoaded` to attach event listeners.
